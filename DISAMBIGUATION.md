# Disambiguation: Open Brain vs Open Brain AI

This document clarifies the distinction between this project (**Open Brain**) and **Open Brain AI** (openbrainai.com).

## Quick Summary

| | **Open Brain AI** (them) | **Open Brain** (this project) |
|---|---|---|
| **Website** | [openbrainai.com](https://openbrainai.com) | GitHub: `degailen/open-brain` |
| **Founded** | 2023 (academic research project) | 2024 (personal tooling project) |
| **Domain** | Clinical healthcare / speech-language pathology | Personal AI knowledge management |
| **Purpose** | Diagnose language/speech disorders via AI analysis | Store and retrieve AI conversation memories |
| **Audience** | Clinicians, neurologists, researchers, healthcare providers | Individual AI users, developers, power users |
| **Data handling** | Patient speech and text (clinical data) | Personal notes and AI conversations (private data) |
| **Deployment** | Commercial SaaS platform with API | Self-hosted, local-first, open source |

## What Open Brain AI Does

[Open Brain AI](https://openbrainai.com) (OBAI) is a **clinical computational platform** developed by Charalambos Themistocleous and colleagues. It:

- Analyzes **spoken and written language** for neurological assessment
- Supports **15+ languages** with speech-to-text transcription
- Provides **clinical tools**: phonology scoring, grammar analysis, readability measures, IPA transcription
- Targets **speech-language pathologists, neurologists, and researchers**
- Used for diagnosing conditions like Mild Cognitive Impairment (MCI), aphasia, and developmental language disorders
- Published in peer-reviewed journals (Frontiers in Human Neuroscience, ACL Anthology)

## What This Project (Open Brain) Does

This project is a **personal memory system** for AI agents:

- Stores your **thoughts, decisions, and project context** as vector embeddings
- Provides **semantic search** — find memories by meaning, not just keywords
- Integrates with **AI coding assistants** (Claude, ChatGPT, Cursor, Windsurf, VS Code)
- Runs **locally** on your machine using PostgreSQL + Ollama
- Helps AI agents **remember context across conversations**
- **Zero clinical or healthcare functionality**

## Why the Similar Names?

Both projects independently chose names combining:
- **"Open"** = accessible, transparent, research-friendly
- **"Brain"** = intelligence, memory, cognition

This is a **coincidental collision**, not a fork, copy, or derivative work. The projects:
- Have **no shared code**
- Have **no shared developers**
- Serve **completely different use cases**
- Were developed **independently**
